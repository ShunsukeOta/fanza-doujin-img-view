# Onboarding implementation

オンボーディングは初回利用者にReaderの基本操作を短時間で体験してもらうための操作チュートリアルです。説明スライドを眺める形式ではなく、実際のジェスチャーをその場で試せる構成にします。

## 表示条件

- 通常Feedでは `swipe-preview:onboarding-v2` が未完了の端末だけ表示する
- 「スキップ」または最終画面の「はじめる」で完了状態を `localStorage` に保存する
- `localStorage` が利用できない場合は `sessionStorage` へフォールバックする
- `/work/{cid}` の共有作品URLは対象作品へ直接入るためオンボーディングを表示しない。このスキップでは完了状態を保存しない
- マイページの「操作ガイド」からは完了済みでもいつでも再表示できる
- 匿名データ削除では `swipe-preview:` の端末状態をまとめて削除するため、オンボーディング完了状態もリセットされる

## 3ステップ

1. **作品切替**
   - 「作品は上下で切り替える」と明示する
   - デモ画面内で実際に上スワイプを検出する
   - 成功時は次作品へ切り替わる簡易Readerデモと `OK` フィードバックを表示する
2. **漫画ページ送り**
   - 「漫画は左右で読む」と明示する
   - デモ画面内で左右どちらのスワイプも検出する
   - 成功時は `01 / 12` から `02 / 12` へページが切り替わる
   - 画面端タップと読む方向設定の存在も短く案内する
3. **保存と購入導線**
   - いいね / 保存 / サンプル読了後のFANZA導線だけを説明する
   - 不要な操作説明を増やさず、Feed開始までの時間を短くする

練習ジェスチャーは必須ではなく「次へ」で進めます。操作に不慣れなユーザーには体験を提供し、すでに理解しているユーザーには摩擦を増やさない設計です。

## 描画・パフォーマンス方針

- オンボーディング全体を左右スワイプしてステップ移動する処理は持たない。Readerの左右スワイプ学習と競合させない
- ステップ切替のたびにMain全体を `key` で再マウントしない
- 3D `perspective`、Visual全体の `transform: scale()`、`backdrop-filter` 多用を使用しない
- 動く要素は練習前の指ガイドだけに限定し、`transform` / `opacity` のみを使う
- 指ガイドのループ回数は有限とし、常時アニメーションさせない
- 実際のドラッグ中はCSS custom propertyをDOMへ直接更新し、重いReact再描画を発生させない
- `prefers-reduced-motion: reduce` では指ガイドのアニメーションと不要なtransitionを停止する
- 低い画面では要素寸法を直接縮め、Visual全体をtransformで縮小しない

## アクセシビリティ

- `role="dialog"` / `aria-modal="true"` を使用する
- ステップ見出しへフォーカスを移し、内容変更を認識できるようにする
- モーダル内でTabフォーカスを循環させる
- `Escape` で閉じられる
- 練習エリアはキーボードの `ArrowUp` / `ArrowLeft` / `ArrowRight` でも成功状態にできる
- マイページから操作ガイドを閉じた際は元のフォーカスへ戻す

オンボーディング完了前は作品Feedをマウントしないため、説明中の操作を作品の impression / dwell として計測しません。完了後にFeedと閲覧位置復元ライフサイクルを開始します。
