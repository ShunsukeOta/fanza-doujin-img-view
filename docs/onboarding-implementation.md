# Onboarding implementation

現在は検証用として、メインページを新規表示するたびにオンボーディングを表示します。

- 閲覧済みフラグは localStorage / sessionStorage / Cookie に保存しません。
- 「スキップ」または最終画面の「はじめる」で、そのアクセス中のみオンボーディングを完了します。
- オンボーディング完了後に作品フィードをマウントするため、説明閲覧中の impression / dwell を作品閲覧として計測しません。
- 保存済み・マイページからメインへ復帰するための位置復元処理は、オンボーディング完了後に開始します。
- 将来「初回のみ」へ切り替える場合は `MainExperience` の表示判定に永続フラグを追加します。
