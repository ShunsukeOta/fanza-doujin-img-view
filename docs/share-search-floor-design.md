# 作品共有・詳細検索・フロア切替設計

## 目的

初回リリースは同人漫画のみを提供しつつ、将来の「同人漫画 / 女優動画 / 素人動画」3フロア展開へUI・ナビゲーション境界を先に整える。

## 作品共有

- canonical作品URL: `/work/{cid}`
- 旧 `/?cid={cid}` は301でcanonicalへ統一する
- `work.php` がDBから作品情報を取得し、React起動前にOGP / X Card / canonicalをHTMLへ埋め込む
- 共有URLは年齢確認後、対象作品Readerへ直接入る
- 作品URLは現段階では `noindex` を維持し、SEO公開判断とは分離する

## 詳細検索

- `/search` を現在の絞り込みSheetとは独立した検索画面として提供する
- `/api/search` → `SearchService` → MariaDB の責務分離とする
- 同人漫画では作品名・サークル・シリーズ・ジャンル・価格・最低評価・最低サンプル枚数・最低レビュー件数・並び順を検索可能とする
- 検索結果から `/work/{cid}` へ遷移してReaderを開始する
- 将来は同一Search Shellへフロア固有条件を追加する

## フロア切替

共通 `FloorTabs` で以下を定義する。

- 同人漫画: 利用可能
- 女優動画: 準備中
- 素人動画: 準備中

Feed / 詳細検索 / 保存済みで同一フロア定義を利用する。動画2フロアのデータ取得・Viewerは今回の実装対象外とする。

## グローバルメニュー

下部メニューは「読む / 検索 / 保存 / マイページ」の4項目とする。上部フロアタブは「何を見るか」、下部メニューは「何をするか」の責務を持つ。
